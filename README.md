# HistoDelta project page

Project page for *HistoDelta: Forecasting Serial Histology by Learning Only What Changes*: https://vanlinlin.github.io/HistoDelta/

Static HTML/CSS/JS, no build step. To preview locally, run `python -m http.server` in this folder and open http://127.0.0.1:8000 (the page loads JSON, so `file://` does not work).

Data: skin pairs from COBRA (CC BY-NC-SA 4.0; images and heatmaps derived from it are shared under the same license), prostate volumes from PCa_Bx_3Dpathology (TCIA, CC BY 4.0). Layout inspired by [Nerfies](https://nerfies.github.io/).
